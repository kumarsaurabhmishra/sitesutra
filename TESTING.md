# Try SiteSutra locally

Open http://localhost:8000/work/ for both examples. Each card has a direct demo link and a separate design-story link. Clicking the illustration also opens the demo.

## Homeware demo
Open http://localhost:8000/demos/olive-earth/
1. Choose Ceramics, Textiles, then All objects. Only matching items appear.
2. Open Materials & care on a product. Enter/Space also works from keyboard focus.
3. Add Clay vase and Cotton throw to the demo bag. Open Bag in the navigation.
4. Increase/decrease quantities, remove one product, and empty the bag. Counts and status messages update.
5. Try Shop, Materials, About, Design story, and All examples links.

This is a local demonstration, with no checkout, payment, order or stored customer information. Reload resets the bag.

## Architecture demo
Open http://localhost:8000/demos/form-space/
1. Use Homes to reach the two project concepts.
2. Open both project stories; try Studio and Approach links.
3. Select Enquire. Submit empty fields to see validation.
4. Enter a name, project type, city/town, and goal. Square footage is optional; negative values are rejected.
5. Preview the brief. The result says no enquiry or appointment has been sent.
6. Use Design story or All examples to return to SiteSutra.

The architecture examples are fictional visual studies, not real buildings or professional architectural advice.

## Real booking
Open http://localhost:8000/#booking. Cal.com uses the supplied 15-minute event. Pick a date and time to inspect its real booking form. Pressing Confirm would create a real booking through Cal.com; this action was not performed in verification. Calendar sync and notification delivery require correct settings in your Cal.com account.

## Layout and access
Try all pages on desktop and narrow mobile. Links and controls have visible keyboard focus. Tab moves through controls; Enter activates links, and native details work with Enter/Space. The illustrations are original and demos use plain English with Indian-home contexts.

The website is local preview only; nothing has been published in this revision.
